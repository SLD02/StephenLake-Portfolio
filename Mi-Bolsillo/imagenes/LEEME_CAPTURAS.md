# Capturas de Mi Bolsillo

Guarda aquí **capturas de la aplicación real**, preferiblemente de una cuenta de demostración con datos inventados:

- `inicio.png`
- `estadisticas.png`
- `presupuestos.png`
- `metas.png`
- `ajustes.png`

Se recomienda recortar el contenido sensible y usar un tamaño similar entre las capturas.
Cuando tengas las imágenes, añade al README del proyecto:

```markdown
![Pantalla de inicio](imagenes/inicio.png)
![Estadísticas](imagenes/estadisticas.png)
```

No muestres datos reales, correos privados, tokens o contraseñas.
